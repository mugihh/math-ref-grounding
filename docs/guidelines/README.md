# Annotation guidelines

- `annotation_guideline_en.pdf`: English reference-grounding guideline.
- `annotation_guideline_ja.pdf`: Japanese translation of the same guideline.

These are the guideline versions used for the released annotation task. They
describe mention identification, box granularity, object classes, linking,
transcription correction, and optional source-video consultation.

The PDFs contain no annotator names, lab contact details, or compensation
records. They are released as documentation under the data/documentation terms
described in `LICENSES.md`.
